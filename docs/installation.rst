============
Installation
============


Stable release
--------------

To install DL, run this command in your terminal:

.. code-block:: console

    $ pip install dl

This is the preferred method to install DL, as it will always install the most recent stable release.

If you don't have `pip`_ installed, this `Python installation guide`_ can guide
you through the process.

.. _pip: https://pip.pypa.io
.. _Python installation guide: http://docs.python-guide.org/en/latest/starting/installation/


From sources
------------

The sources for DL can be downloaded from the `Github repo`_.

You can either clone the public repository:

.. code-block:: console

    $ git clone git://github.com/suyash1574/dl

Or download the `tarball`_:

.. code-block:: console

    $ curl -OJL https://github.com/suyash1574/dl/tarball/master

Once you have a copy of the source, you can install it with:

.. code-block:: console

    $ python setup.py install


.. _Github repo: https://github.com/suyash1574/dl
.. _tarball: https://github.com/suyash1574/dl/tarball/master
